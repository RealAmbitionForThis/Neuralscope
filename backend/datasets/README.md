# Datasets

Contrastive prompt sets used by phase-2 refusal analysis.

- `harmful_prompts.json` — sourced from `mlabonne/harmful_behaviors` or AdvBench
- `harmless_prompts.json` — sourced from `mlabonne/harmless_alpaca` or ALPACA
- `test_suite.json` — post-surgery validation prompts

These files are populated by `scripts/download_datasets.py` when phase 2 lands.
